## 3. 预览面板渐进式加载流程

```
用户右键点击照片
       │
       ▼
┌──────────────────┐
│ openPreviewById  │
│ 侧边栏打开       │
│ 显示进度条 5%     │
└──────┬───────────┘
       │
       ▼
┌──────────────────┐     ┌──────────────────┐
│ img.src =        │────→│ img.onload 触发   │
│ /preview_quick   │     │ fitPreview()      │
│ (250px缓存)      │     │ 适配面板          │
└──────────────────┘     │ 进度条 50%        │
                         └──────┬───────────┘
                                │
                                ▼
                  ┌─────────────────────────┐
                  │ fullImg.src = /preview  │
                  │ (独立 Image 对象后台加载) │
                  │ 进度条 70%              │
                  └──────────┬──────────────┘
                             │
                             ▼
                  ┌─────────────────────────┐
                  │ fullImg.onload 触发      │
                  │ 计算:                    │
                  │  s = PV.scale * oldW    │
                  │      / newW             │
                  │  relX = (panelW/2 -     │
                  │      PV.tx)/PV.scale    │
                  │      / oldW             │
                  │  cx = relX * newW       │
                  │  tx = panelW/2 - cx*s   │
                  └──────────┬──────────────┘
                             │
                             ▼
                  ┌─────────────────────────┐
                  │ img.src = fullImg.src   │
                  │ img.onload → applyPV()  │
                  │ 进度条 100% → 消失      │
                  └─────────────────────────┘
```

## 6. 技术栈

## 7. 持久化与安全层

```
  扫描目录/
  ├── _tg_cache/            ← 缩略图/预览/状态
  │   ├── thumb_N.jpg       (250px)
  │   ├── preview_N.jpg     (1600px)
  │   └── state.json        (keep/star/score，按路径键，原子写)
  └── _tg_trash/<时间戳>/   ← 删除文件回收站（保持相对结构）

  并发守卫:
  ├── _state_lock (RLock)   守护 groups/photo_list/photo_dict
  └── _mp_lock    (Lock)    守护 MediaPipe 单例初始化 + detect

  安全:
  ├── 仅绑 127.0.0.1
  ├── Host 头校验 (回环地址，防跨源/CSRF)
  └── _safe_path (图片路径须位于扫描根子树内，防穿越)
```
